# outputs/

This directory is intentionally **empty in git**. Generated images and
videos are excluded via `.gitignore` — they're reproducible from the
workflow files in `workflows/` plus the prompts in `prompts/`, and can be
large in aggregate, so they aren't tracked.

## Layout

| Folder    | Contents                     |
|-----------|-------------------------------|
| `images/` | Images generated by ComfyUI  |
| `videos/` | Videos generated by ComfyUI  |

## Regenerating outputs

1. Open the relevant workflow JSON from `workflows/` in ComfyUI.
2. Use the corresponding prompt from `prompts/` (if applicable).
3. Run the workflow — ComfyUI will write results into these folders.

## Keeping a specific result

If you want to keep a particular output long-term, don't rely on this
folder — move a copy somewhere outside this repo, or reference material you
want to keep *in* the repo (e.g. input images for img2img) belongs in
`references/`, which is tracked.
