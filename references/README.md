# references/

This directory is intentionally **empty in git**. It's meant for your own
original art, character reference sheets, or other images you use as input
to workflows (img2img, ControlNet pose references, etc.) — none of that
gets pushed to GitHub.

Note: images dragged directly into ComfyUI (via its Load Image node) are
saved to ComfyUI's own `input/` folder, which lives outside this repo
entirely (e.g. `D:\ComfyUI\ComfyUI_windows_portable\ComfyUI\input\`) — those
were never at risk either. This folder is for anything you deliberately
copy into the repo itself for organization.
